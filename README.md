# QuizMaster

QuizMaster - это приложение с тестами по веб-разработке

## О проекте
В приложении можно будет пройти тесты по направлениям:
- JavaScript
- HTML и CSS
- Vue.js
- Node.js

Пользователь может выбрать тему из списка и проверить свои знания.

## Используемые технологии
- HTML
- CSS
- JavaScript
- Vue 3
- Vue Router
- Vite
